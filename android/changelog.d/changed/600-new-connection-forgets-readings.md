- **A new connection forgets the previous one's readings** — Every new connection (Connect, RETRY, an automatic start or an automatic reconnect after a drop) now shows each reading as not received until this connection reads it again, and the running figures restart; before, only RETRY blanked a few polled values and an automatic reconnect showed the old ones for up to about 30 s. Peaks are kept; the session knock log and the knock count are kept across an automatic reconnect and start fresh at Connect or RETRY (`LiveTelemetry.newConnection`).

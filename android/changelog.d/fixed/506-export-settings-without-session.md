- **A diagnostic export made before any adapter session carries the SETTINGS block** — an export with no session (no connection yet, demo mode included) left the block out and said nothing. It now writes the current settings with a `Source    : current settings (no adapter session)` line, and the detail JSON adds `settingsSource` (`session` or `current`) beside `settings`, whose keys are unchanged. Additive, so the export schema stays 1 (`DiagnosticReportBuilder.exportSettings`). ([#506](https://github.com/klexical/openRS_/issues/506))

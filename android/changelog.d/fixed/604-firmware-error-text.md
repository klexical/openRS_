- **Failed drive mode, ESC and WebSocket connections show fixed wording** — A failed firmware command showed and exported the adapter's status line or the phone's raw exception text, and a refused WebSocket upgrade exported up to 80 characters of the adapter's reply headers. `FirmwareFailure` now gives each failure one fixed text, with only the HTTP status code's three digits, and an upgrade or command succeeds only on the status code itself (101 / 200), never on those digits found elsewhere in the reply. ([#604](https://github.com/klexical/openRS_/issues/604))

- **A spliced adapter line could pass as a one-byte frame on an ID that carries 8 bytes** — a frame shorter than its CAN ID's decoder needs (for example one byte on 0x0F8) is now refused and counted with the refused frame lines, under its own count in LINK INTEGRITY / `linkIntegrity.refusedShortFrames`, instead of reaching the frame inventory as an unknown frame. IDs the app does not decode keep any length (`CanDecoder.minBytes`). ([#551](https://github.com/klexical/openRS_/issues/551))

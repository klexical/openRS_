- **A drive no longer stores a held speed as a fresh one** — while 0x130 frames stopped arriving, each 1 Hz point stored the last decoded speed again, so the CSV, GPX, RaceChrono and TrackAddict files and the average speed carried a speed no frame had sent. A point now records the speed only while 0x130 is at most 2 s old (`DriveState.freshSpeedKph`); otherwise the exports write an empty field, TRIP's chart, map and replay show no speed there, and the drive's average and top speed leave it out. ([#515](https://github.com/klexical/openRS_/issues/515))

- **Sport and Track requests confirm on a phone set to Arabic or Persian** — the 0x420 detail key that corroborates a Sport / Track report was built with the phone's locale, so its digit could come out in Arabic-Indic or Persian digits and then never matched, and such a request could not read as confirmed. `CanDecoder.stampDetail` now formats the key with `Locale.ROOT` (found with [#564](https://github.com/klexical/openRS_/issues/564)).

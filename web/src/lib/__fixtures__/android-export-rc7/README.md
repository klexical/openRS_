The two ZIPs are complete exports from emulator runs of the rc.7 release build (a synthetic adapter and synthetic GPS; see
the header of the test that imports each). Their file names and contents carry the real times of those runs. No car, person
or place is involved. The maintainer accepted them as published test data on 2026-11-12. New fixtures use invented times
(the `20260101_000000` convention of the other fixture folders).

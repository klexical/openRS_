- **A drive CSV written in non-Latin digits is refused, not imported empty** — openRS_ before v2.2.7-rc.7 wrote most numbers in the phone's own digits, so on a phone using Arabic-Indic or Persian digits a drive imported with a time axis and rpm and no other reading. Such a file is now refused with its file, row and column, and asks for the drive to be exported again with v2.2.7-rc.7 or later, as a decimal-comma file already was (`lib/import.ts`). ([#396](https://github.com/klexical/openRS_/issues/396))
